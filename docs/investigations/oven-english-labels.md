# NV51K7770S English labels

The `LCD_OV_WALL_16K` oven uses Title Case for English control, sensor and
cooking-mode labels. Examples include **Start Cooking**, **Cook Time**,
**Energy Saving**, **Convection Bake** and **Keep Warm**. Acronyms such as AI
keep their existing capitalization.

Separate translation entries limit these changes to this oven. Other appliance
models retain their labels, and the other nine languages retain their wording
and capitalization. The English text lives in the translation catalog rather
than being capitalized at runtime.

Existing entity IDs, custom names, disabled settings, mode values and command
routes are preserved. Verification covers upgrades in all ten languages, both
divider states, offline startup and unaffected appliance fixtures.
